# RESQNET – Offline Disaster Rescue Network

## About the Project
RESQNET is an offline emergency communication system designed to help people send SOS messages during disasters when internet and mobile networks are unavailable.

## Problem Statement
During floods, earthquakes and other emergencies, communication networks may fail, making it difficult for affected people to contact rescue teams.

## Proposed Solution
RESQNET aims to provide an offline communication system using ESP32 and LoRa technology.

## Key Features
- Emergency SOS message transmission
- Offline communication
- Rescue station dashboard
- Emergency message storage
- Emergency priority classification

## Technologies
- Python
- ESP32
- LoRa
- Arduino IDE
- Streamlit
- SQLite
